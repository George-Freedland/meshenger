Meshenger lets phones and laptops text, call and host websites over Bluetooth: no Wi-Fi, no SIM, no servers.

**Install**
- Mac: open Meshenger-macOS.dmg and drag Meshenger to Applications.
- Windows: extract the zip and run meshenger.exe. If Windows warns you, click More info → Run anyway.
- Android: open Meshenger-Android.apk on your phone and allow installs from your browser.
- iPhone: join the TestFlight beta at https://george-freedland.github.io/meshenger/
- Raspberry Pi relay: see "Pi as a standalone gateway" in the README.

Install it on two devices, turn Bluetooth on, and you have a mesh.
